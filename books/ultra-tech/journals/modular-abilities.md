Chip Slots: Use this for cyborgs with removable hardware.

Computer Brain: This is for AIs, and cyborgs with implanted computers, who download and install ability programs (skills and advantages run using the Computer Brain advantage) instead of plugging them in as chips. A computer can theoretically run tens, hundreds, or even thousands of programs at once, but ability programs are limited by the multi-tasking ability of the machine’s consciousness. This usually restricts the computer to only a couple of programs, depending on the robot’s template.
