# Journal map: GURPS High-Tech

Which rule issue each page of the High-Tech rules journal belongs to (#356). The pages are
`journals/<key>.md`, listed in `journals/index.json`; a page the layout defeated is written in
`journals-by-hand/<key>.md` and copied over it. When an issue's switch exists, its pages take
the switch id as `"rule"` in `index.json`. A page with no issue is text only: flavour, an
overview, or a rule no switch implements.

241 pages, 8 by hand; 209 belong to 39 rule issues (the 38 of #357-#394, and #427 for Zen Marksmanship).
