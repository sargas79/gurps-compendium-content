Acrobatics is as important as any combat skill for capoeiristas, action heroes, and other flashy fighters. It’s required to use combat rules such as Acrobatic Attack (p. 107), Acrobatic Dodge (p. B375), Acrobatic Movement (pp. 105-107), and Acrobatic Stand (p. 98), which are at least semi-realistic, and Chambara Fighting (pp. 128-130), which is cinematic. Some fighting styles allow an “Acrobatic Feint,” too; see Feints Using Non-Combat Skills (p. 101).
