Use these modifiers for Information spells that work over long distances, such as “Seek” spells.

| Distance | Penalty |
| --- | --- |
| 200 yards | 0 |
| 1/2 mile | -1 |
| 1 mile | -2 |
| 3 miles | -3 |
| 10 miles | -4 |
| 30 miles | -5 |
| 100 miles | -6 |
| 300 miles | -7 |
| 1,000 miles | -8 |

Add another -2 per additional factor of 10.
