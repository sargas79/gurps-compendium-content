Some traits – including Luck, Serendipity, and Wild Talent – rely on real time. This modifier makes such an advantage use game time (p. 497) instead. If the ability usually works at least once per real hour, you get uses per game day equal to its maximum uses per real hour; e.g., Ridiculous Luck, which works every 10 real minutes, gets six uses per game day. If the ability is rated in uses per session, you get that many uses per game week; e.g., Serendipity 3 gives three uses per game week.

These ratios may feel unfair in a combat-heavy game – or in any game with lots of “slow” time. The GM is welcome to adjust them, multiplying frequency by anywhere from 2 (e.g., “twice per hour” becomes “four times per game day,” and “once per session” becomes “twice per game week”) to 7 (e.g., “once per hour” becomes “seven times per game day,” and “twice per session” becomes “14 times per game week”).
